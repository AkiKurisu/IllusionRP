# UnityRHI

A fork of Kuan-Mi's [UnityRHI](https://github.com/Kuan-Mi/UnityDLSSNR) (`top.kuanmi.unityrhi`) with bindless resource table support for IllusionRP.

The native plugins ship in `Plugins/x86_64` and are built from [AkiKurisu/UnityDLSSNR](https://github.com/AkiKurisu/UnityDLSSNR). See the upstream repository for usage.
